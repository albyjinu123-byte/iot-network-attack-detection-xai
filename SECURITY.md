# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within SentinelAI, please report it responsibly:
- Email the project maintainers with the details of the vulnerability.
- Please do not disclose vulnerabilities publicly in issues or pull requests until a patch has been released.
- Include reproduction steps and potential impact in your report.
