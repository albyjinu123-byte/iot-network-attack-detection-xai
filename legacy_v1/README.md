# SentinelAI - Legacy v1 Archive

This directory contains the initial prototype scripts and baseline experiments developed during the preliminary research phase of SentinelAI.

## Contents
- `download_data.py`: Initial raw download script targeting CICIoT2023 mirrors.
- `create_dataset.py`: Prototype sampling and schema inspection utility.
- `src/baseline_models.py`: Preliminary baseline algorithms (Logistic Regression and Decision Trees) evaluated prior to the soft voting ensemble.

> [!NOTE]
> For active production inference, retraining, and full-stack cyber console operations, refer to `sentinel-ai/`.
